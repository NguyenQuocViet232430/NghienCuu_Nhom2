# RAIC — Phase 2: Frontend Prototype & Research Alignment Report

> **Current Project Status:** **FRONTEND PROTOTYPE DEVELOPMENT ONLY (Phase 2)**  
> **Backend Integration Policy:** The AI algorithms and model checkpoints are being independently trained and evaluated by the research team. This frontend operates fully in **Mock / Research Simulator Mode** using realistic MS COCO 2014 data contracts, ready for future backend handoff.

---

## 1. Executive Summary & Scope Clarification

In accordance with the updated Phase 2 requirements:
- **No Backend Execution:** No Python services, FastAPI server launching, model training, or checkpoint dependencies are required.
- **Visual & Functional Excellence:** The React 19 + TypeScript + Vite web demo has been transformed into a production-grade, highly interactive, and visually sophisticated research dashboard.
- **Thesis-Level Realignment:** All data structures, UI flows, and evaluation matrices have been strictly refactored around the **4 Official Research Levels**:
  - **Level 1 — Baseline:** Pure vision ViT-B/32 + Transformer Decoder (no retrieval).
  - **Level 2 — Simple RAG Fusion:** FAISS caption retrieval from MS COCO 2014 + simple concatenation/prefix fusion.
  - **Level 3 — RAG with Reranking:** Top-20 FAISS candidates filtered via CLIP score and object consistency.
  - **Level 4 — Proposed RAIC:** Confidence-aware Gated Cross-Attention Fusion.

## 2. Completed Frontend Features (Active in Prototype)

### A. Core Navigation & Research Shell
- **Tabbed Workspace:** Seamless switching between `Workspace`, `Baseline vs RAIC` (dedicated side-by-side mode), `FAISS Candidates`, `Evaluation`, `Ablation (L1-4)`, `History`, and `Settings`.
- **Dual Themes:** High-contrast Dark Mode (`#090D15`) and Clean Light Mode (`#F7F9FC`) with instant toggle and `localStorage` persistence.
- **Simulated / Mock Indicator:** Transparent badge in the header clearly stating that outputs are generated by the *Mock Research Simulator*.

### B. Image Ingestion & Preset Benchmark Library
- **Input Channels:** Drag-and-drop file upload, file explorer selection, and **3 one-click benchmark images** (COCO val2014 samples: golden retriever, ocean surfer, vintage train).
- **Validation:** Format validation (`JPG`, `PNG`, `WEBP`) and file size limits (15MB) with clear alert banners.

### C. 5-Stage Animated Inference Pipeline
Simulates the synchronous multi-stage inference sequence over 2.5 seconds:
1. `Vision Feature Extraction` (CLIP ViT-B/32 dense embeddings)
2. `Baseline Level 1 Generation` (Greedy visual prefix decoding)
3. `Candidate Caption Retrieval` (FAISS IndexFlatIP over 414K MS COCO 2014 captions)
4. `Level 3 Knowledge Reranking` (CLIP similarity + object consistency)
5. `Level 4 Proposed RAIC Generation` (Confidence-aware Gated Cross-Attention)

### D. Interactive Multi-Level Comparison Workspace
- **Side-by-Side Dual Caption Cards:** Compares Level 1 Baseline (`"A dog jumping in a field with a toy."`, CIDEr: 1.250) vs Level 4 Proposed RAIC (`"A golden retriever leaps across a sunny grass field to catch a red flying disc."`, CIDEr: 1.348, +7.8%).
- **All 4 Levels Progression View:** Toggle mode displaying the progressive qualitative leap across Level 1 &rarr; Level 2 &rarr; Level 3 &rarr; Level 4 with corresponding simulated CIDEr consensus and latency metrics.

### E. Interactive Multi-Mode Image Stage
- **Original View:** High-resolution rendering with zoom controls (75% to 250%), reset, and fullscreen modal.
- **Attention Mode:** Dynamic focal heatmap simulation updating in lockstep with the selected token.
- **Entities Mode:** Visual bounding boxes with classification labels and confidence scores.

### F. Confidence-aware Gated Explainability Workspace
- Clicking any word in the Level 4 caption reveals the mathematical **Gate Value** $\gamma \in [0, 1]$:
  - Dual-color gauge measuring the ratio of visual patch reliance ($\gamma$) vs candidate text memory reliance ($1 - \gamma$).
  - Explanatory logic: Visual Dominance ($\gamma > 0.65$), Knowledge Dominance ($\gamma < 0.35$), or Balanced Gated Fusion ($\gamma \approx 0.5$).
  - Grounding links connecting the token to active training captions.

### G. FAISS Candidate Retrieval Inspector
- Displays Top-20 candidates retrieved from the MS COCO 2014 training split.
- Compares initial FAISS cosine similarity against Level 3 Rerank scores ($R$).
- Clearly highlights candidates that are **Admitted to Decoder** (Rank $\le$ Top-K) vs **Filtered/Pruned**.

### H. Corpus Evaluation & Ablation Study
- **Primary Metric:** CIDEr is explicitly prioritized as the consensus metric, accompanied by `BLEU-1`, `BLEU-4`, `METEOR`, `ROUGE-L`, and `SPICE`.
- **Real Report Importer:** Allows uploading a real evaluation JSON (`report.json`) to update the dashboard with empirical experimental runs.
- **Ablation Dashboard:** 6 comparative configurations across Levels 1–4 and parametric Top-K sensitivity ($K=3, 5, 10$) with dynamic metric selector and baseline delta calculation.

### I. Persistence & Scientific Export
- **Audit Log History:** Locally stores previous runs (both Baseline and RAIC captions, timestamps, and CIDEr scores) with instant search and record deletion.
- **Export Utilities:** Direct clipboard copying, structured JSON download, and CSV table export with 4-level metrics.
